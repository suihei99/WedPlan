# WedPlan 💍

## Overview
**WedPlan** is a comprehensive Web and Mobile-Based Wedding Budgeting and Management System. This repository houses the web application and the API backend that powers the mobile experience. 

The platform is designed to help couples seamlessly plan, track, and manage their wedding preparations, from budget allocation to vendor coordination.

## 🚀 Tech Stack
* **Backend & Web Framework:** [Laravel](https://laravel.com/) (PHP)
* **Frontend Styling:** [Tailwind CSS](https://tailwindcss.com/)
* **Database:** MySQL
* **Mobile Application:** Flutter *(Note: The mobile counterpart is managed in a separate repository)*

## ✨ Key Features
* **Comprehensive Budgeting:** Track estimated costs versus actual expenses to stay within budget.
* **Vendor Management:** Organize vendor details, contracts, and payments in one place.
* **Task Scheduling:** Step-by-step checklists to ensure no detail is missed before the big day.
* **API Integration:** Robust RESTful API to sync data in real-time with the WedPlan Flutter mobile app.

Make sure you have the following installed on your local machine:
